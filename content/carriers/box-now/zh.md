BOX NOW 是一家在希腊、塞浦路斯、保加利亚和克罗地亚专营全天候 24/7 自有快递柜投递的包裹服务商。在斯洛文尼亚，它同样运营快递柜，但也支持商家选择签收送货上门。你可以在所在国家 BOX NOW 网站的“Track your parcel”页面、BOX NOW 应用或上方输入框中输入 10 位包裹 ID（parcel ID）查询包裹。单号来自商家下单时发给你的邮件、短信或 Viber 消息。

## BOX NOW 运单号在哪里找

BOX NOW 在五个国家的帮助页面均指出，单号在你收到的邮件、短信或 Viber 消息中。官网查件只需输入单号，无需邮编。希腊语联系页称之为“voucher ID”。

| 格式（虚构） | 含义 |
| --- | --- |
| `7482910375` | BOX NOW 包裹 ID：10 位数字。 |
| `482910` | 不是运单号：这是打开快递柜格口的 6 位 PIN 码。 |

BOX NOW 未公布各位数字的含义。PIN 码只有在包裹投入快递柜后才会发送。其他快递也使用 10 位数字：如果商家邮件写的是另一家公司，请去那家查询。一条消息都没收到？单号在商家那里：参见[如何查找运单号](guide:find-tracking-number)（英文）。

## BOX NOW 物流状态含义

各国英文查询页面的部分文案略有不同。下表先列希腊与塞浦路斯版本，有差异处再附保加利亚和克罗地亚版本。

| BOX NOW 状态 | 对你的含义 |
| --- | --- |
| `Your order has been prepared`、`New - On the way to our warehouse`、`New - to be picked up from sender` | [已生成面单](guide:tracking-statuses)（英文）：商家已下单预订配送。 |
| `BOX NOW has not yet received the parcel from eshop` | 上行下方的说明：BOX NOW 尚未从网店收到包裹。 |
| `Your parcel has been placed in the locker`、`Being delivered` | 寄件人刚把包裹投入寄件快递柜，或（boxnow.hr 上的 `Being delivered`）正放在柜里等 BOX NOW 快递员取走，并不是待你自提。 |
| `Your parcel is at the BOX NOW sorting center` | 已到达 BOX NOW 分拣中心，正在中转。 |
| `Box Now has started the delivery to the Locker`、`BOX NOW has started the delivery` | 正在送往你选定的快递柜。 |
| `Your Parcel is located at the locker`、`Waiting for pick up` | 待取件：你的取件 PIN 码会通过短信发来。 |
| `Your parcel has been delivered`、`Delivered` | 你已从快递柜取走包裹。 |
| `Delivery has expired`、`Expired` | 标红显示：取件时限已过。 |
| `Parcel search - We will update you shortly`、`To be found` | BOX NOW 正在查找包裹。 |
| `To be found`、`Lost` | BOX NOW 判定包裹丢失。 |
| `Parcel has been returned`、`Returned` | 已退回寄件人。 |
| `Canceled`、`Cancelled` | 寄件人取消了运单。 |

“Placed in the locker”听起来像已经到柜等你取，其实那是寄件人刚投递的起步状态；只有显示 *located* at the locker 或 `Waiting for pick up` 时才可取件。同样，`Being delivered` 并不代表包裹已到你附近。`To be found` 在保加利亚和克罗地亚指正在查找，在希腊和塞浦路斯指已判定丢失。

包裹在柜待取期间，查询页会显示“Last pick up time”（最晚取件时间）以及“Extend the pick up time”（延长保管时间）和“Resend Pin”（重发 PIN 码）两个按钮。

## 如何从 BOX NOW 快递柜取件

**派送日。** 在希腊和塞浦路斯，BOX NOW 周一至周六派送，周日及法定节假日不派送。希腊与塞浦路斯之间互寄需 3 个工作日。

**开箱取件。** 包裹送达你的快递柜后，BOX NOW 会短信发送 PIN 码：在柜机键盘输入即可开箱，短信和邮件中的链接还提供导航指引。在克罗地亚，若已安装 BOX NOW 应用，通知会改为邮件与应用内推送。弄丢 PIN 码？在查询页点“Resend Pin”并输入运单登记的手机号即可重发。

**保管时长。** 各国标准不同，BOX NOW 的常见问题与服务条款偶尔也不一致：

- **希腊：** 至少 24 小时，点“Extend the pick up time”可再延 24 小时。
- **塞浦路斯：** 英文常见问题写明至少 24 小时，可延长 24 小时。
- **保加利亚：** 常见问题写 48 小时并可免费再延 48 小时；服务条款写 72 小时，另可联系 BOX NOW 申请再延最多 48 小时。
- **克罗地亚：** 96 小时。
- **斯洛文尼亚：** 常见问题与服务条款均写 48 小时。

请以查询页上的“Last pick up time”为准。逾期未取的包裹会由 BOX NOW 回收并退回寄件人。

**更换快递柜。** 在希腊和塞浦路斯，BOX NOW 常见问题指引在应用中使用“Change Locker”功能（每票限改一次），并说明目标快递柜满箱时会改投最近的一组。保加利亚常见问题同样指引使用应用，其条款允许在取件截止前向 BOX NOW 申请更改一次。在克罗地亚，仅服务条款提到可在应用中改投。

**货到付款。** 快递柜不收现金，需通过 BOX NOW 邮件或短信中的链接在线支付，查询页也会显示“PAY”按钮。

**退货。** 可将包裹投进任意 BOX NOW 快递柜：保加利亚、克罗地亚和斯洛文尼亚面向部分合作商家提供 BOX NOW 退货表单，希腊则提供 BOX NOW Returns。

## BOX NOW 包裹丢失、延误或破损

**尚未送达。** BOX NOW 常见问题称通常是商家尚未交寄订单：请联系商家。等待时间参见[物流为什么停止更新](guide:tracking-not-updating)（英文）。

**柜门打不开。** 在希腊请发邮件至 dema@boxnow.gr（附上姓名和订单号）；在塞浦路斯请致电 +357 240 42000。

**包裹破损或拿错（希腊）。** 发邮件至 dema@boxnow.gr，附上姓名、手机号、voucher ID 和包裹照片。在克罗地亚，BOX NOW 条款要求在打开快递柜后 4 小时内报损。

**丢失或严重延误。** 在希腊和塞浦路斯，BOX NOW 条款规定赔偿归签约方寄件人（网购即商家），因此请向商家申请退款并同步向 BOX NOW 报备。保加利亚条款也允许收件人书面发邮件至 support@boxnow.bg 索赔。希腊和保加利亚的索赔期为 6 个月，塞浦路斯用户协议为 2 个月；在希腊，延误超过 15 个工作日即视为丢失。克罗地亚条款规定国内包裹 3 个月、国际包裹 6 个月，发至 podrska@boxnow.hr；斯洛文尼亚时限相同，书面发至 info@boxnow.si。

## 用 Peek 跟踪 BOX NOW 包裹

[Peek](/) 无法仅凭 10 位数字识别出 BOX NOW 包裹，因此会依次向符合该形态的承运商查询：BOX NOW、DHL eCommerce Iberia，以及视具体数字和输入方式再问 [DHL Express](carrier:dhl-express)、ACS Courier、Geniki Taxydromiki 或 Packeta，在部分国家还会问 DHL Freight。若都未查到，Peek 会转向物流查询服务，接着再问 DPD Ireland 和 Estafeta，以 33 或 34 开头时问 GLS Hungary，以及尚未问过的 DHL Freight。如果只有 BOX NOW 查到，Peek 自动归入 BOX NOW；若多家同时查到，则由你选择（但若 DHL Express 查到且 ACS 与 Geniki Taxydromiki 均未查到，则直接归入 DHL Express）。否则点“更换”手动选择“BOX NOW”。粘贴 boxnow.gr、boxnow.cy、boxnow.bg、boxnow.hr 或 boxnow.si 上带 `/track?track=…`（路径中可含语言如 `/en/track`）的查询链接，Peek 会立刻识别为 BOX NOW。

随后 Peek 会展示当前状态、带地点的扫描历史、在途预计送达日、目的国、签收时间，以及包裹待取或已取时的快递柜名称。快递柜地址与定位、取件截止时间、格口尺寸、付款信息、寄件人和邮编均不显示，因此最晚取件时间请查看 BOX NOW 官网。

Peek 的文案可能与 BOX NOW 官网略有不同：待取件显示为 `Parcel has reached its final destination, waiting for pickup`，已取件显示为 `Parcel has been delivered`。`Expired`、`Delivery has expired`、`Lost`、`Parcel search - We will update you shortly` 以及寄件人取消均归在“需要留意”下。当你打开包裹页，或在派送当天开启通知时，Peek 最多每 10 分钟查询一次。连续两天无新动态（在“已生成面单”或“已揽收”状态下为 12 小时）后改为每小时查询一次，在“已生成面单”下连续七天无动态后改为每 6 小时一次。如果包裹在“已生成面单”、“已揽收”或“运输中”状态下连续四天无新记录，Peek 会显示“自……起没有物流更新”（附该记录日期）以及“向 BOX NOW 寻求帮助”链接。通知可选“每次扫描”、“重要环节”或“仅派送当天”。Peek 无法替你延长取件时间或重发 PIN 码。

## 关于 BOX NOW 物流查询的常见问题

### BOX NOW 派送需要多久？

收到包裹后，希腊本土 1 个工作日、海岛 2 个工作日；塞浦路斯 1 个工作日。保加利亚常见问题称网店处理订单次日送达（英文版也写 24 小时内）。克罗地亚条款为网店到快递柜 3 个工作日（柜到柜 5 个工作日），英文常见问题写 5 个工作日、克罗地亚语写 5 天，首页写网店处理后 48 小时。斯洛文尼亚常见问题写交寄后工作日 24 小时内，条款写 2 至 3 个工作日。

### BOX NOW 怎么运作？

在网店结账时选择一组 BOX NOW 快递柜。包裹送达后 BOX NOW 会短信发来 PIN 码，在柜机键盘输入即可开箱取件。

### 需要下载 BOX NOW 应用吗？

不需要：PIN 码通过短信发送，网页查询页也无需应用即可使用。希腊、塞浦路斯和保加利亚的常见问题指引通过应用（iOS 和 Android）更换快递柜；保加利亚条款也允许联系 BOX NOW 更改一次。
