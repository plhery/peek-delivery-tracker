C Chez Vous 在法国专门负责超过 30 公斤的大件网购配送（例如家具和大型家电），按预约时段送货上门或配送至自提点。承运商由商家在你下单时指定。你可以使用 C Chez Vous 通过邮件或短信发送的订单号，在 [C Chez Vous 追踪页面](https://www.cchezvous.fr/suivi-colis) 上查询，或直接粘贴到上方输入框中。

## C Chez Vous 订单号在哪里找

C Chez Vous 按订单号而非单个包裹号追踪。其追踪页面要求输入 “le numéro de commande que vous avez reçu par mail ou par sms”，即你在邮件或短信中收到的订单号。网站仅提供法语版本。进入订单详情后页面会列出每一件包裹（“Colis 1 : N°…”），但追踪时始终按整笔订单查询。邮件找不到了？请参阅 [如何查找追踪单号](guide:find-tracking-number)（英文），或直接联系商家。

该页面展示了两种参考号格式，以下字符均为虚构示例：

| 格式 | 说明 |
| --- | --- |
| `TRXN54BD83` | 10 位字符：4 位字母、2 位数字、4 位字母或数字。 |
| `1TRXN482917--69002` | 11 位字符、两个连字符，后接收货邮编。 |

部分其他承运商的单号外观相近。以 `1G` 开头的单号（例如 `1G4829173654`）属于 [GEODIS](carrier:geodis)。8 位纯数字（例如 `48291736`）也被 [Heppner](carrier:heppner)、[Colisweb](carrier:colisweb) 和 [Mondial Relay](carrier:mondial-relay) 使用。

如果页面提示 `La commande est introuvable`（找不到该订单），请核对字符是否有误，再查看邮件确认是否由其他承运商配送。

## C Chez Vous 物流状态含义解析

追踪页面会显示一条带法语标题的进度条以及下方的一句说明。送货上门订单按以下顺序推进：

| C Chez Vous 原文 | 对你的含义 |
| --- | --- |
| `En attente` | 等待中：订单正在发往 C Chez Vous 运输网络，尚未确定派送日期。 |
| `Prise de rendez-vous` | 预约派送时间：C Chez Vous 暂时联系不上你，请你主动致电确认日期。 |
| `En préparation` | 备货转运中：订单已进入 C Chez Vous 网络，派送日期已确定。 |
| `En livraison` | 正在发往 C Chez Vous 区域配送中心，派送日期已确定。 |
| `Livré` | 已送达你家中。 |
| `Annulée` | 订单出现异常，请致电客服处理。 |

如果是自提点配送，最后几步有所不同：

| C Chez Vous 原文 | 对你的含义 |
| --- | --- |
| `Disponible au point retrait` | 已到达自提点，页面会同时标明最晚取件日期。 |
| `Terminé` | 你已完成取件。 |

最容易让人误解的是 `En livraison`。它字面上看起来像“正在派送中”，但下方的法语说明实际表示订单正发往区域分拨平台，司机未必已经在送往你家的路上。

当尚未确定日期时，日期栏会显示 “À définir”（待定），页面也会提示你致电客服。

## C Chez Vous 派送规则：预约、时间段与自提点

**预约时段。** C Chez Vous 提供可更改的 5 小时派送时间段。据其常见问题页面说明，派送前一天你会收到邮件，将 5 小时时段缩小到 2 小时。配送时间为周一至周日（视所在地区与所选服务而定）；按 C Chez Vous 公布的数据，全程耗时 1 至 14 天。

**修改预约。** 你可以凭订单号在追踪页面点击 “Modifier la livraison” 修改日期，也可以通过电话修改。修改地址、电话、邮箱或派送备注需至少提前 48 小时，更换地址可能导致预约顺延。取消预约需至少提前 24 小时致电。如需更改服务等级（例如从 Eco 升至 Standard），请联系商家。

**派送当天。** 送达前约 30 分钟你会收到包含司机实时地图的短信或邮件；司机也可能在到达前约 20 分钟致电（有时使用隐藏号码）。

**配送服务等级。** 配送员送货到位程度取决于你向商家购买的服务：

- **Eco（C Devant）：** 送到独栋住宅门口或公寓楼一楼大厅，搬运入户由你自行完成，交接前需出示身份证件。
- **Standard（C Dedans）：** 搬入你指定的房间，不限楼层，但不包含安装。
- **Premium（C Installé）：** 拆箱、安装并通电测试，不含水路、电路或木工改造。

如果司机现场判断需要两人协同搬运（例如旋转楼梯、无电梯），C Chez Vous 会重新安排双人配送预约。

**派送未成功。** 司机会留下未投递通知单（“avis de passage”），当天不会再次派送。C Chez Vous 表示客服会在 24 小时内联系你重新商定预约时间。

**自提点。** C Chez Vous 在法国设有 400 个自提点。订单到达后你会收到短信和邮件通知，自提保管期为 15 天。

## C Chez Vous 配送延误、破损或缺少包裹

你的购物合同是与商家签订的。C Chez Vous 没有公布面向收件人的理赔表单或索赔期限，因此商品本身的问题应先联系商家。

**当天未送达。** 请先等到预约时段结束，再致电客服；客服需要等待司机完成当天路线汇报。如果页面连续多天没有变化，请参阅 [物流停止更新怎么办](guide:tracking-not-updating)（英文）。

**商品破损。** 请当着司机的面开箱检查商品，并将每一处损坏写在签收单或司机的手持终端上。如果发错商品，请当场拒收并联系商家售后。

**少件或缺配件。** 请致电 C Chez Vous 客服报备。

**商品故障或退货。** 故障件和退货由商家负责安排。如果商家拒绝退货服务，C Chez Vous 表示可以单独提供上门取退服务。

- **电话：** 09 70 17 05 58，服务时间为巴黎时间周一至周五 8:00–18:00，周六 9:00–13:00。这是一个 09 开头号码而非 0800 免费电话，网站未标注通话资费。

C Chez Vous 未对收件人公布电子邮箱、在线客服聊天或邮寄地址。C Chez Vous 的 [联系表单](https://www.cchezvous.fr/contact) 面向商业销售团队，不受理包裹派送咨询。商品相关问题请联系商家。

C Chez Vous 不属于 GEODIS。它由法国邮政集团（La Poste Groupe）旗下的 Geopost 持股 80%，Rhenus 持股 15%。

## 使用 Peek 追踪 C Chez Vous 订单

将形如 `TRXN54BD83` 的订单号粘贴到 [Peek](/)，Peek 会查询 C Chez Vous 的订单页面，一旦 C Chez Vous 查到该订单，就显示“C Chez Vous 有这个包裹的记录。”来自 cchezvous.fr（`/suivi-colis/` 后接参考号）的链接适用于任何参考号。其他参考号（包括末尾带邮编的长编号）直接输入时不会对应任何快递公司：请点“更换”并选择 C Chez Vous，或粘贴链接。

在 Peek 中，订单已登记与预约派送阶段显示为“已生成面单”，备货及发往区域配送中心阶段显示为“运输中”，送达后显示为“已签收”。物流历史会在每次状态变更时新增一行，按当前步骤命名为“Order registered”或“Scheduling delivery”，随后是“Order being prepared”或“Order on its way to the regional depot”，最后是“Delivered”。自提点订单的历史依次显示发往自提点、已在自提点待取（状态变为“待取件”）以及已从自提点取走（状态变为“已签收”）。当一笔订单包含多个包裹时，Peek 会展示进度最慢的那一件。你的预约日期在签收前会显示为预计送达日，若追踪页面提供时间段也会一并显示。由于 C Chez Vous 不提供历史节点、地点与时间戳，每条记录的日期以 Peek 首次检测到该变化的时间为准。

需要注意几处限制：`En livraison` 在 Peek 中仍显示为“运输中”，因为 C Chez Vous 自己的说明写明订单仍在发往区域平台，且追踪页面没有派送中这一步；Peek 也不会读取 `Annulée`，被取消的订单只会停止更新。

Peek 会读取你的姓名（显示在“收件人”下方）与收货地址，但不会展示商家、你的电话和邮箱或所订商品。当你打开该订单，或在派送当日开启通知时，Peek 最多每 10 分钟检查一次，其余时间每小时检查一次，并可以发送“每次扫描”、“重要环节”或“仅派送当天”通知。由于没有派送中这一步，Peek 不会切换到派送当天每 2 分钟的检查，“仅派送当天”也只会发送已签收提醒；“重要环节”还会在自提点订单可取件时提醒你。连续两天没有新动态后（订单仍显示“已生成面单”或“已揽收”时为 12 小时），Peek 每小时检查一次；在“已生成面单”停留七天且无新动态后，每 6 小时检查一次（派送当天除外）。Peek 无法替你修改预约。

## 关于 C Chez Vous 物流查询的问题

### C Chez Vous 有免费客服电话吗？

未公布免费电话。客服电话为 09 70 17 05 58，属于 09 号段，网站未说明资费标准。

### 如何联系 C Chez Vous 的送货司机？

C Chez Vous 不公开司机电话。司机可能会在到达前约 20 分钟联系你，有时会使用隐藏号码；如需主动沟通，请致电客服。

### C Chez Vous 周六和周日派送吗？

可以。C Chez Vous 周一至周日均可派送，具体取决于你的所在地区以及商家为你选择的服务。
