中国邮政（China Post）是中国的国有国家邮政运营商，EMS 是其旗下的特快专递品牌。如果你在速卖通、Temu、SHEIN 或其他跨境网店下单后收到了以 `CN` 结尾的国际快递单号，它就是由中国邮政签发的，包裹飞抵目的国后将由你所在国家的国家邮政继续用同一个单号完成派送。你可以前往中国邮政官网（`ems.com.cn`）查询，或者直接把单号粘贴到上方查询框里。单号通常位于网店的发货通知邮件或订单详情中。

## 中国邮政国际单号格式：怎么看、各字母什么意思

中国邮政国际单号遵循万国邮政联盟（UPU）统一的 S10 标准：2 位字母 + 9 位数字 + `CN`，共 13 位字符。第一位字母代表邮件类别（以下示例数字均为虚构，校验位有效）：

| 单号（虚构） | 类别说明 |
| --- | --- |
| `LT482917367CN` | `L` 开头：带全程跟踪的国际小包（e邮宝/挂号小包类函件）。 |
| `RR482917367CN` | `R` 开头：国际挂号函件/挂号小包。 |
| `CP482917367CN` | `C` 开头：国际普通包裹。 |
| `EA482917367CN` | `E` 开头：EMS 国际特快专递。 |
| `UA482917367CN` | `U` 开头：平邮小包（UPU 定义为「不提供面向客户的追踪」），抵达目的国后通常不会再有后续扫描。 |
| `ZS48291736751` | `ZS`、`ZC` 或 `ZA` 加 11 位数字：中国邮政查件系统同样支持的号段。 |
| `LP48291736051428` | 不是中国邮政，而是 [菜鸟（Cainiao）](carrier:cainiao) 物流参考号。 |
| `YT4829173605142839` | 不是中国邮政，而是 [云途物流（YunExpress）](carrier:yunexpress) 的运单号。 |

9 位数字里的最后一位是校验位，抄错任何一位数字通常都会导致单号校验无效。按照万国邮联规定，每件国际邮件只使用唯一一个 S10 编号，所以包裹进入收件国后，直接在你本国邮政网站输入同一个 `CN` 单号就能查到当地扫描。注意，部分邮件在中国邮政官网查询时会要求验证运单上预留联系电话的后四位。

## 中国邮政物流状态是什么意思

中国邮政的轨迹以中文书写，地点放在方括号内（下文用 `【…】` 表示）：在中国境内显示具体邮局或处理中心名称，出境后常显示中文国家名（如 `【英国】`、`【美国】`）。按包裹实际流转顺序，常见节点含义如下：

| 中国邮政原文 | 对你的实际含义 |
| --- | --- |
| `已揽收` | 中国邮政已实际收到包裹。 |
| `邮件到达【…】` | 包裹到达指定的中国邮政网点或处理中心。 |
| `邮件离开【…】，正在发往下一站` | 包裹已离开该处理中心发往下一站。 |
| `【…】退回，备注:安检退回` | 处理中心安检环节将其退回复查处理（并非立即退回给发件人）；Peek 会标记为「需要留意」。 |
| `送交出口海关` | 已提交中国出口海关申报。 |
| `出口海关/留存待验` | 中国出口海关留存查验。 |
| `出口海关/放行` | 中国出口海关已放行。 |
| `【…】已出口直封` | 已在中国国际互换局封发直邮出境。 |
| `已交承运商运输` | 已移交航空或干线承运商运输。 |
| `航空公司接收`、`航空公司启运` | 航空公司已接收邮件并起飞运出。 |
| `飞机进港` | 国际航班已降落。 |
| `到达寄达地处理中心` | 包裹已到达目的国邮政处理中心。 |
| `送交境外进口海关` | 已提交收件国进口海关。 |
| `境外进口海关留存待验` | 收件国海关扣留查验。 |
| `寄达地海关允许进口` | 收件国进口海关已放行。 |
| `离开【…】处理中心` | 已离开目的国处理中心，前往地方邮局。 |
| `已到达【…】投递局` | 已到达负责你地址的当地投递邮局。 |
| `【…】安排投递`、`邮件正在派送中` | 邮递员正在外出派送。 |
| `已试投/投递失败` | 当地邮政尝试投递但未能成功。 |
| `【…】已妥投`、`已签收` | 包裹已成功送达或签收。 |
| `已退回` | 包裹已被退回给寄件人。 |

后半程的扫描来自目的国邮政回传给中国邮政的同步数据，有时甚至在妥投后才回传。直接用同一单号查询目的国邮政（或让 Peek 自动切换）能更及时地看到最后几步。

## 中国邮政包裹在收件国由哪家邮政派送

中国邮政负责出口运输，包裹抵达收件国后交由当地国家邮政清关并投递到户：

- **美国**：美国邮政（USPS）。
- **英国**：皇家邮政（Royal Mail），根据 [英国政府海外包裹税务指南](https://www.gov.uk/goods-sent-from-abroad)，由皇家邮政代理办理英国清关并在需要缴纳增值税或关税时通知收件人；如果是 `E` 开头的 EMS 国际特快专递，英国境内则由 Parcelforce 负责派送。
- **爱尔兰**：爱尔兰邮政（An Post）。根据 [爱尔兰税务局欧盟统一处理费新闻稿](https://www.revenue.ie/en/corporate/press-office/press-releases/2026/pr-092926-handling-fee.aspx)，自 2026 年 11 月 1 日起欧盟按每类商品征收 2 欧元统一处理费；如结账时网店未代收，An Post 会在投递前连同关税和增值税一并收取。
- **加拿大**：加拿大邮政（Canada Post）。若在其查件工具里查不到记录，加拿大邮政会要求联系发件人通过起运国邮政发起查单。
- **澳大利亚**：[澳洲邮政（Australia Post）](carrier:australia-post)。海外来件是否全程可查取决于起运国所选邮件类别，且海关清关最长可能需要 15 天。

派送次数、未投递通知卡以及邮局代保管期限均执行你本国邮政的规定；请参考 [错过派送怎么办](guide:missed-delivery) 和 [未领取包裹退件说明](guide:uncollected-parcel)。进口关税、增值税和处理费详情见 [包裹海关扣留与清关指南](guide:customs)。

## 中国邮政物流不更新、丢失或被退回怎么办

- **暂时查不到扫描。** 在中国邮政实际扫码揽收前，查件系统不会显示任何信息——此时可能只是卖家刚生成了面单。请向卖家确认是否已经交邮。若超过两天依然查不到且第三方查询服务也无记录，Peek 会提示核对单号。
- **离开中国后长时间无更新。** 航班起飞到目的国邮政首次扫入之间常常会空窗多日，此时请直接用同一单号查询目的国邮政。如果是 `U` 开头的平邮小包，入境后很可能彻底不再更新。参见 [物流为什么停止更新](guide:tracking-not-updating) 和 [中国直邮包裹跟踪指南](guide:tracking-from-china)。
- **显示已妥投却没收到。** 投递是由目的国邮政执行的，请先查看当地邮政的轨迹和签收凭证，再联系网店。见 [显示已签收但未收到](guide:delivered-not-received)。
- **丢失或破损。** 根据 [中国邮政英文联系页面](https://english.chinapost.com.cn/en/category/1408/3925-1.htm)，所有国际邮件的正式查询须由寄件人前往当地邮局提交；加拿大邮政和澳洲邮政同样要求由寄件人通过寄出国邮政发起调查。因此收件人应尽快通知卖家或购物平台申请退款或重发。参见 [包裹丢失怎么办](guide:lost-parcel)。
- **显示 `已退回`。** 包裹正在退回发件人，请联系卖家商定退款或补发。参见 [包裹退回寄件人](guide:returned-to-sender)。

## 中国邮政客服电话与联系方式

根据 [中国邮政英文官网](https://english.chinapost.com.cn/) 公布的客服热线：

- **EMS 与物流业务**：`8610 11183`。
- **邮政业务**：`8610 11185`。

由于国际邮件正式查单必须由寄件人提交，直接联系网购卖家通常更高效；而涉及目的国派送、改期或清关缴税时，请联系你所在国家的国家邮政。

## 用 Peek 跟踪中国邮政包裹

只要 2 位字母 + 9 位数字 + `CN` 的校验位正确（如虚构单号 `LT482917367CN`、`RR482917367CN`、`CP482917367CN`、`EA482917367CN`），且不是 `YY` 开头（`YY` 开头属 YYpost），[Peek](/) 会立刻自动识别为中国邮政，查询框里会显示 China Post 和「识别出的快递公司」；`ZS`、`ZC`、`ZA` 加 11 位数字（如 `ZS48291736751`）也会直接识别。如果校验位错误，Peek 不会匹配中国邮政，请仔细核对卖家邮件中的单号。其他格式也可直接粘贴（Peek 支持 4,500 多家快递），如需手动调整请点击添加页的「更换」或详情页的「更换快递公司」；详情页同样提供「向 China Post 寻求帮助」链接直达中国邮政联系页面。

Peek 直接查询中国邮政官方轨迹。如果官方接口要求验证手机号后四位，Peek 会改试 `ems.com.cn` 的公开预览接口而不会向你索要手机号；如果公开预览也拒绝且第三方服务没有记录，Peek 会提示需要额外信息，此时请携带手机号后四位到中国邮政官网查询。因为中国邮政对访客有时仅返回最新三条扫描，Peek 会在可能时补充收寄日期，并在第三方查询服务拥有更完整历史时整合展示。

Peek 展示标准阶段（「已生成面单」「已揽收」「运输中」「清关中」「派送中」「派送未成功」「已签收」「已退回寄件人」「需要留意」等）、每条扫描的网点城市和目的国，并把中国邮政的北京时间记录与回传的海外当地时间分别准确换算为你设备的本地时区。Peek 会自动去除寄收件人资料、联系方式、业务名称和裸坐标；中国邮政不提供预计送达日期、重量或自提点信息。

对于 `CN` 结尾的国际邮政单号，一旦中国邮政轨迹标注了目的国（未标注时则参考你手机区域或访问所在国），Peek 会用同一个单号同步向当地国家邮政查询（如美国 USPS、英国 Royal Mail 或 EMS 对应的 Parcelforce、爱尔兰 An Post、加拿大 Canada Post、澳大利亚 Australia Post 等），待当地邮政产生最新扫描后自动接力切换并完整保留中国邮政前期轨迹。

Peek 对中国邮政（含派送当天）保持每小时检查一次；切换到目的国邮政后，遵循实际派送包裹的邮政自己的频率。最新扫描仍是「已生成面单」「已揽收」或「运输中」且连续四天无新扫描时，Peek 会提示「包裹在长途航班上、在海关或遇到周末时，常常暂时没有动静。Peek 会持续向 China Post 查询。」，超过三周无动静则提示「已超过三周没有新动态。如果还没收到，请联系卖家。Peek 会持续向 China Post 查询。」。

通知范围可选「每次扫描」「重要环节」或「仅派送当天」。Peek 无法替你联系中国邮政、目的国邮政或卖家。

## 关于中国邮政国际物流查询的常见问题

### 我的中国邮政包裹现在到哪儿了？

看最新一条扫描即可：括号里是中国国内城市或处理中心说明仍在国内；出现 `到达寄达地处理中心` 起就说明已经抵达收件国，可以直接用同一单号在当地国家邮政查件。

### 为什么中国邮政物流一直不更新？

最常见的原因是包裹正处于国际航空中转或等待收件国海关清关，介于中国邮政最后一条扫描和当地邮政首条扫描之间。建议直接用同一单号查本国邮政；若单号以 `U` 开头，境外本来就不提供跟踪扫描。

### 中国邮政国际快递要寄多久？

时效完全取决于卖家选择的服务类别（如 EMS 特快、e邮宝、挂号小包或平邮）以及目的国清关速度，请以网店或购物平台给出的预计送达时间为准。

### 物流记录里的「已妥投」是什么意思？

就是「已签收/已投递成功」，例如 `【英国】已妥投` 代表已在英国完成投递。如果显示已妥投但你没拿到包裹，请第一时间联系本国邮政并查看 [显示已签收但未收到](guide:delivered-not-received)。

### 中国邮政的包裹到美国或英国后由谁派送？

由当地国家邮政用同一个单号派送：美国是 USPS，英国普通邮件和小包是 Royal Mail、EMS 特快专递（`E` 开头）是 Parcelforce。
