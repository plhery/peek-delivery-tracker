壹号专线（FIRST LINE，深圳壹号供应链有限公司）是一家总部位于深圳的跨境物流货代企业，主要为中国跨境电商卖家将包裹运往海外（以美国为主），并在目的国交由当地承运商完成末端投递。它隶属于一代国际集团（1ST 集团），该集团旗下多家货代均签发以 `1ST` 开头的运单号。你可以在 `firstline56.com` 首页的查询框中输入单号（提交后会打开壹号专线“追踪单号”页面），或直接把单号粘贴到上方查询框中。单号一般由卖家随订单发货信息提供。

## 壹号专线（FIRST LINE）单号格式规则

壹号专线官网并未公开单号编码规范。与一代国际集团旗下其他成员一样，其运单通常由 `1ST` 加 11 位数字构成。以下示例均为虚构单号：

| 单号 | 说明 |
| --- | --- |
| `1ST68492037154` | `1ST` 加 11 位数字：一代国际集团运单号，可在壹号专线官网查询。 |
| `9400 1837 4920 6158 3724 91` | `94` 开头的 22 位数字：美国邮政 USPS 面单号，用于美国境内末端派送。 |

**相同前缀可能对应集团内其他货代。** 一代国际集团旗下包含四家业务主体：一代国际（1st Agent International）、壹号专线（FIRST LINE）、摆渡一下（Ferry-Boat）和万国优联（Universal Best Union），它们共用 `1ST` 开头的运单前缀。如果某个 `1ST` 单号在壹号专线页面查不到记录，可能属于集团内另外三家公司之一。

**在哪里找到单号。** 在购物店铺的发货详情里查看。需要注意，卖家在电商平台上填写的承运商名称可能是 USPS、China Post 或 FIRST LINE，因为壹号专线允许卖家在平台选用这些承运商名义回填。集团常见问题也提到，美国 USPS 等末端转单号通常会在包裹到达深圳仓库后 6 至 9 天生成，因此部分商家会直接给你末端单号。如找不到单号，可参阅[如何查找快递单号](guide:find-tracking-number)。

## 壹号专线（FIRST LINE）物流状态含义解析

壹号专线官网追踪页面为中文界面，但具体轨迹行均为英文。以下按包裹从中国发往海外的常见顺序整理壹号专线自身节点：

| FIRST LINE 英文轨迹 | 对你的含义 |
| --- | --- |
| `Forecast has been received` | 卖家已向系统提交订单预报信息，壹号专线尚未收到实物包裹。`Parcel information received` 含义相同。 |
| `Order received` | 当地派送商（如 UniUni）已收到订单数据，但尚未拿到包裹。 |
| `Barcode scanning` | 包裹抵达壹号专线深圳仓库后的首次条码扫描。 |
| `Shipment arrived` | 同样是深圳仓库的入库扫描，并非到达你所在国家。 |
| `Packaged` | 已打包完毕，准备出境。 |
| `Leaving Scan` | 包裹已出库离开仓库。 |
| `Export customs declaration completed` | 已在深圳完成中国出口报关，并非被海关扣留。 |
| `Depart from facility to service provider` | 正从壹号专线仓库转运至下一段干线服务商。 |
| `Hand over to airline` | 出口报关后已在香港机场交由航空公司。 |
| `Next stop destination airport` | 已登机飞往目的国机场，地点栏此时仍显示香港机场。 |
| `Arrived at destination airport` | 航班已落地目的国机场，接下来进入进口清关。 |
| `The package is being submitted for customs clearance` | 航班落地后正在办理进口清关，Peek 会显示为“清关中”。 |
| `The package has been cleared through customs` | 进口清关已完成放行，Peek 恢复显示为“运输中”。 |
| `Customs broker picked it up` | 放行后清关代理已提货准备移交派送，不再停留于海关。 |
| `The package has been transferred to the service provider` | 清关代理已将包裹移交末端派送商。 |

包裹进入美国后，轨迹会直接转发当地派送商的原版英文扫描直至签收——实测历史记录中常见 USPS、GOFO 或 UniUni 的措辞。以 GOFO 为例，其派送日扫描为 `Out for Delivery`（Peek 显示为“派送中”），妥投记录通常写作 `Delivered,` 后接放置地点（如 `Door/Yard`）以及 `For delivery issues & tracking support, contact GOFO at` 附带联系方式（Peek 显示为“已签收”）。由于壹号专线官网不会主动标注末端派送商名称，这些轨迹措辞往往是判断当地由哪家派送的重要线索。

每条轨迹的时间均使用扫描发生地的当地时间（先为深圳或香港时间，随后转为美国当地时间），且页面不附带时区标识，因此美国境内的扫描时间看起来可能早于最后一条中国扫描的小时数。若系统查无此单，会返回中文提示 `未找到此单号信息`。

## 谁负责派送壹号专线包裹

壹号专线负责将包裹运出中国、在目的国安排清关并移交本地承运商完成最后一公里派送：

- **美国空运小包**：由 USPS 或当地商业快递派送，壹号专线官网业务页明确提及 USPS 与 DHL eCommerce，门到门参考时效为 7 至 16 天。
- **美国海运小包**：搭乘美森快船赴美后由[联邦快递（FedEx）](carrier:fedex)或 USPS 派送，门到门参考时效为 19 至 31 天。
- **加拿大小包**：空运至温哥华或多伦多清关后交由 Canada Post 派送，壹号专线称清关完成后约 2 至 7 天送达。
- **欧洲空派专线**：空运至布拉格并在捷克清关，再由 UPS 派送至德国、法国、意大利、西班牙、英国等 20 多个国家的住宅、商业地址及亚马逊仓库，单件最低按 12 公斤计费，卖家运费已含税费。

美国专线仅覆盖美国本土 48 个州，不派送至阿拉斯加、夏威夷、波多黎各、美属维尔京群岛、关岛、邮政信箱（PO Box）、军事地址或亚马逊仓库地址。壹号专线的美国和加拿大包裹专线均以完税后交货（DDP）模式向卖家销售，进口税费由发货方承担。关于清关的更多知识，可参阅[包裹被海关扣留怎么办](guide:customs)。

壹号专线未面向收件人公布派送尝试次数、通知单或自提点保管规则，一切以实际派送商规定为准。官网也不展示末端转单号，若需联系当地派送商改约投递，请向卖家索取末端承运商单号。

## 壹号专线包裹未到或追踪停滞怎么办

**一直停在 `Forecast has been received`。** 说明壹号专线还没有扫到实物包裹。一代国际集团常见问题告知卖家，下午 5 点前交货的包裹通常当天上线追踪；如果数天无新进展，请联系卖家核实是否已实际发件。

**出口扫描后无更新。** 接下来是国际航班与进口清关阶段，连续几天没有新记录属正常现象。如果远远超出上述参考时效仍无变化，请联系卖家跟进。详见[为什么快递物流停止更新](guide:tracking-not-updating)。

**显示已签收但没拿到。** 根据壹号专线业务条款，若末端派送商显示妥投但收件人未收到，壹号专线仅协助核查而不承担赔付责任。请第一时间联系当地派送商和卖家核实，详见[显示已签收但未收到包裹](guide:delivered-not-received)。

**丢件或破损。** 理赔申请须由卖家在发货后 60 天内发起，且壹号专线不对运输途中破损或延误提供赔付。作为买家，请直接联系卖家或下单平台申请退款或重发；若发生外包装破损，集团 FAQ 要求收件人先在当地向派送方报备并保留回执编号及外箱照片，供卖家提交核查。详见[包裹丢失](guide:lost-parcel)。

**包裹退回。** 美国专线无法投递的包裹不会退回中国，而是退回壹号专线的海外仓；如果卖家未在 14 天内支付费用安排重派，包裹将被销毁。因此一旦看到退件迹象，务必立刻通知卖家处理。详见[包裹退回寄件人](guide:returned-to-sender)。

截至 2026 年 10 月查阅壹号专线中文官网（`firstline56.com`），其联系我们页面列出了客维中心及办公地址：中国广东省深圳市宝安区福永街道怀德翠岗工业园 5 区 36 栋 3 楼，未注明办公时间或支持语言。[一代国际集团官网](https://www.1st56.com/group/aboutus/)另设有“投诉建议”入口，需填写电话、电子邮箱和留言内容。

这些通道主要面向签约发货的跨境卖家，没有面向个人收件人的售后服务。遇到订单问题请优先联系卖家，涉及末端投递细节则找当地派送商。

## 使用 Peek 追踪壹号专线（FIRST LINE）包裹

只要输入 `1ST` 加 11 位数字的单号（无论大小写，带或不带空格），[Peek](/) 就能立即自动识别为 FIRST LINE。Peek 不解析壹号专线的网页链接，请直接粘贴单号本身。若需手动更改承运商，可在添加包裹时点击“更换”，或在已添加包裹详情页点击“更换快递公司”。

Peek 直接查询壹号专线追踪系统，展示包裹阶段（“已生成面单”、“已揽收”、“运输中”、“派送中”、“已签收”、“清关中”）、最多 100 条历史轨迹、去掉邮编后的扫描地点，以及按扫描当地时钟读取的时间。包括转发自 USPS、GOFO 或 UniUni 的英文轨迹均会保留原文显示，仅精确的 `Delivered` 会显示为 Peek 对应的中文状态词。由于壹号专线官网不返回目的地国家、末端派送商名称、末端转单号或签收证明，Peek 也不会显示这些字段。Peek 唯一能展示的预计送达信息，来自被转发的 USPS `Out for Delivery, Expected Delivery …` 轨迹：当该条为最新扫描且包含当日送达时段窗口时，Peek 会展示该窗口；若仅写了最晚送达时刻，则不额外生成预计时间，因为“派送中”本身已代表当日投递。Peek 不会自动切换到 USPS、GOFO 或 UniUni 追踪，如果卖家提供了末端转单号，可以将其作为新包裹单独添加。

在壹号专线官网正常响应期间，Peek 最高每 10 分钟刷新一次；在包裹进入派送当天，从当地时间早上 6 点起（若已知当日派送窗口，则从窗口开启前半小时起）最高每 2 分钟检查一次；若改由第三方聚合追踪服务返回数据，则每 15 分钟检查一次。连续两天无新动态（或停留在“已生成面单”、“已揽收”满 12 小时）后，刷新频率转为每小时一次。若运输途中长时间静默，Peek 会提示“包裹在长途航班上、在海关或遇到周末时，常常暂时没有动静。Peek 会持续向 FIRST LINE 查询。”；超过三周无更新时，则会提示“已超过三周没有新动态。如果还没收到，请联系卖家。Peek 会持续向 FIRST LINE 查询。”

你可以自由选择“每次扫描”、“重要环节”或“仅派送当天”通知预设。Peek 仅提供追踪更新，不能代你联系壹号专线或卖家。

## 关于壹号专线（FIRST LINE）查询的常见问题

### 1ST 开头的单号是什么物流？

这是一代国际集团旗下货代公司（包括壹号专线 FIRST LINE）签发的运单号，格式为 `1ST` 后接 11 位数字，可在 `firstline56.com` 或 Peek 中追踪。

### 壹号专线的包裹在美国由谁派送？

由美国本地承运商完成末端派送：壹号专线业务页列明了 USPS、DHL eCommerce 和 FedEx，实测追踪记录中也常见由 USPS、GOFO 或 UniUni 派送。官网会直接转发对方的扫描轨迹，但不会在页面上写明具体派送商名称。

### 为什么壹号专线官网查不到我的 1ST 单号？

可能是单号输错、货物尚未入库扫描，或者该单号属于一代国际集团旗下另外三家货代（一代国际、摆渡一下、万国优联）。请先核对单号，再向卖家确认实际承运公司。

### 壹号专线寄往美国通常要多久？

壹号专线向卖家公布的门到门参考时效为：美国空运小包 7 至 16 天，美国海运小包 19 至 31 天。这属于商家业务参考数据，具体收货时间请以订单页面预估为准。
