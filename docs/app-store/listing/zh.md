## Description

```text
我的包裹到哪儿了？

粘贴运单号、快递公司链接或整封发货邮件，或者扫描面单上的条形码。Peek 会从 3500 多家快递公司中找出正在运送包裹的那一家，并在地图上显示它的行程、每一次扫描，以及预计送达的日期。

无需账号，没有广告。

包裹有动静时，我能知道吗？
用 Apple、Google 或邮箱验证码登录后，Peek 会给你发通知：每次扫描都通知、只通知重要环节，或只在派送时通知。包裹送达时，还可以给你发一封邮件。

不止一个包裹？
所有包裹都在同一个列表里，下一个要到的排在最上面，行程显示在地图上。有了账号，你的 iPhone 和网页版 peektracker.com 上是同一个列表。小组件会把下一个包裹放在主屏幕上。

还有别人在等这个包裹？
用链接分享包裹页面，对方不需要安装 App，也不需要账号。还可以把它包装成礼物，里面是什么，送达之前都是个惊喜。

一本收件护照
有了账号，每次签收都会记入你的护照，有的还能换来一枚邮票。和好友比比护照，你的包裹信息不会公开。

3500 多家快递公司
中国邮政、EMS、顺丰速运、菜鸟、京东物流、圆通速递、中通快递、申通快递、韵达速递、极兔速递、德邦快递、云途物流、递四方、燕文物流、香港邮政，以及 DHL、UPS、FedEx、USPS、Royal Mail、Japan Post、La Poste、Swiss Post 等数千家：各国邮政、快递公司和电商平台的物流服务商。

还有这些
• 条形码扫描
• 从“邮件”、“信息”或 Safari 浏览器直接把单号或物流链接分享到 Peek
• 浅色和深色主题
• 简体中文、英语、德语、法语、意大利语、西班牙语、葡萄牙语、巴西葡萄牙语、波兰语和俄语

私密且开源
Peek 不展示广告，也不出售数据。它自己绘制地图，所以没有任何地图服务能看到你的包裹去了哪里。不登录跟踪的包裹会在送达 30 天后被清除。你随时可以在 App 中下载你的数据或删除账号。所有代码都在 GitHub 上：github.com/plhery/peek-delivery-tracker

Peek 独立于它所查询的快递公司。这些公司的名称归各自的所有者所有。
```

## What's new

```text
• 派送中的包裹今天就会送达，所以卡片、小组件和实时活动不再显示日期，只保留快递公司给出的当天送达时段。
• 负责派送的快递公司已收到预报但还没扫描包裹时，卡片现在会显示类似“DHL 已收到预报，尚未收到包裹”的提示，而不是“由 DHL 派送”。
• 已退回寄件人的包裹在退回途中继续被扫描时，现在仍显示为已退回，不会再变回“运输中”。
• 用日文、韩文等其他文字写的地点，现在会显示所在城市和国家，扫描记录和计划步骤都是如此；像“SCARBOROUGH - ON - CANADA”这样的地点，现在也会显示加拿大和国旗。
• 对于提前发布物流轨迹的快递公司，包裹页面现在会说明 Peek 将在真实扫描出现后逐条显示；计划步骤的时间一过就会消失。
• 又有 72 家快递公司有了自己的货车，用的是各自的品牌色；选择快递公司时，在符合单号的快递公司中，你所在国家或地区的会排在前面。
• 现在能识别海运集装箱号：包裹页面会说明这是什么、运单号在哪里，并可以直接选择快递公司。
• 墨西哥和中国的极兔速递（J&T Express）凭收件人或寄件人手机号后 4 位显示扫描记录：现在可以在添加包裹时填写，也可以稍后在包裹页面补填。
• 登录后，如果账号放不下这台设备上的所有包裹，Peek 现在会告诉你有几个包裹留在了设备上。
• 没有账号时：用邮编查询过的包裹不会再要求填写邮编；保存的副本无法读取的包裹会重新回到列表；清除包裹会立即生效，即使没有网络也一样。
• 刷新物流时如果遇到连接错误，不会再同时显示“暂无新动态”；C Chez Vous 的部分步骤现在会用你的语言显示，不再是法语。
```
