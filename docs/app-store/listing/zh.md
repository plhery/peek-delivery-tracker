## Description

```text
我的包裹到哪儿了？

粘贴运单号、快递公司链接或整封发货邮件，或者扫描面单上的条形码。Peek 会从 4500 多家快递公司中找出正在运送包裹的那一家，并在地图上显示它的行程、每一次扫描，以及预计送达的日期。

无需账号，没有广告。

包裹有动静时，我能知道吗？
用 Apple、Google 或邮箱验证码登录后，Peek 会给你发通知：每次扫描都通知、只通知重要环节，或只在派送时通知。包裹送达时，还可以给你发一封邮件。

不止一个包裹？
所有包裹都在同一个列表里，下一个要到的排在最上面，行程显示在地图上。有了账号，你的 iPhone 和网页版 peektracker.com 上是同一个列表。小组件会把下一个包裹放在主屏幕上。

还有别人在等这个包裹？
用链接分享包裹页面，对方不需要安装 App，也不需要账号。还可以把它包装成礼物，里面是什么，送达之前都是个惊喜。

一本收件护照
有了账号，每次签收都会记入你的护照，有的还能换来一枚邮票。和好友比比护照，你的包裹信息不会公开。

4500 多家快递公司
中国邮政、EMS、顺丰速运、菜鸟、京东物流、圆通速递、中通快递、申通快递、韵达速递、极兔速递、德邦快递、云途物流、递四方、燕文物流、香港邮政，以及 DHL、UPS、FedEx、USPS、Royal Mail、Japan Post、La Poste、Swiss Post 等数千家：各国邮政、快递公司和电商平台的物流服务商。

还有这些
• 条形码扫描
• 从“邮件”、“信息”或 Safari 浏览器直接把单号或物流链接分享到 Peek
• 浅色和深色主题
• 简体中文、英语、德语、法语、意大利语、西班牙语、葡萄牙语、巴西葡萄牙语、波兰语和俄语

私密且开源
Peek 不展示广告，也不出售数据。它自己绘制地图，所以没有任何地图服务能看到你的包裹去了哪里。未登录时跟踪的包裹会在送达 30 天后被清除。你随时可以在 App 中下载你的数据或删除账号。所有代码都在 GitHub 上：github.com/plhery/peek-delivery-tracker

Peek 独立于它所查询的快递公司。这些公司的名称归各自的所有者所有。
```

## What's new

```text
• Peek AI：当 Peek 有明确线索时，包裹卡片会在快递公司给出的日期旁显示 Peek 认为它何时送达，“包裹列表”小组件也会在放得下时显示。在包裹页面，点开它的卡片即可看到最可能的日期或时段、原因，以及 Peek 有多大把握。大多数包裹不会显示。可在“设置”中通过“Peek AI”关闭。
• 有些快递公司提前列出的步骤，会在物流记录中折叠到这样一行后面：“其他网站可能显示更多步骤，但那些只是预测”；“查看”会逐条列出，每条附“预计”及其日期。没有新扫描的包裹会注明最后一次扫描的日期。
• 超过预计送达日的包裹会在状态下方显示“预计送达”和那一天。快递公司一给出地址，地图就会指向包裹要去的城市。快递公司没给出地址时，如果你有 Peek 账号，且包裹已进入你通常收件的城市所在的国家，包裹会显示“通常送达地”和那座城市，地图也会按估算画出到那里的剩余路线。
• 如果你告诉 Peek 某个包裹页面有误，现在可以回答“我没有收到”，Peek 会建议下一步怎么做：问问邻居、看看你的信箱，联系快递公司，或者问卖家。
• 助手（测试版，需 Peek 账号）：每个助手那一行会写明唯一要做的事，步骤列在下方。ChatGPT Plus 和 Pro 也能添加 Peek；在美国以外，Gemini 可通过其“Developer Mode”添加 Peek。助手每添加一个包裹，Peek 都会通知你，除非你关闭“助手添加包裹时通知我”。
• 通过邮件添加包裹（测试版）：在 Gmail 中设置需要四步，而不是七步。
• 没有账号时，“设置”中有“通知”：可以开启或关闭，并为这台设备上的所有包裹选择“所有物流动态”“仅重要动态”或“仅派送当天”。登录界面会在你正在做的事情之上打开，完成后带你回到原处。更换包裹的快递公司会保留它的名称和通知；Peek 已清除的包裹仍会保留，并标注“不再更新”。
• 添加包裹时如果没有选择快递公司，而 Peek 建议的快递公司使用邮编查询，就会显示它的邮编栏（选填）。输入 Amazon 单号时，会提供 Peek 的指南，教你找到运单号。
• 修复：昨天寄出、预计明天送达的礼物不再显示今天送达；已签收的包裹会显示是谁派送的；链接中的单号能正确识别；向 DPD 和其他快递公司查询更准确。
```
