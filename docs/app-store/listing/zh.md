## Description

```text
我的包裹到哪儿了？

粘贴运单号、快递公司链接或整封发货邮件，或者扫描面单上的条形码。Peek 会从 3500 多家快递公司中找出正在运送包裹的那一家，并在地图上显示它的行程、每一次扫描，以及预计送达的日期。

无需账号，没有广告。

包裹有动静时，我能知道吗？
用 Apple、Google 或邮箱验证码登录后，Peek 会给你发通知：每次扫描都通知、只通知重要环节，或只在派送时通知。包裹送达时，还可以给你发一封邮件。

不止一个包裹？
所有包裹都在同一个列表里，下一个要到的排在最上面，行程显示在地图上。有了账号，你的 iPhone 和网页版 peektracker.com 上是同一个列表。小组件会把下一个包裹放在主屏幕上。

还有别人在等这个包裹？
用链接分享包裹页面，对方不需要安装 App，也不需要账号。还可以把它包装成礼物，里面是什么，送达之前都是个惊喜。

一本收件护照
有了账号，每次签收都会记入你的护照，有的还能换来一枚邮票。和好友比比护照，你的包裹信息不会公开。

3500 多家快递公司
中国邮政、EMS、顺丰速运、菜鸟、京东物流、圆通速递、中通快递、申通快递、韵达速递、极兔速递、德邦快递、云途物流、递四方、燕文物流、香港邮政，以及 DHL、UPS、FedEx、USPS、Royal Mail、Japan Post、La Poste、Swiss Post 等数千家：各国邮政、快递公司和电商平台的物流服务商。

还有这些
• 条形码扫描
• 从“邮件”、“信息”或 Safari 浏览器直接把单号或物流链接分享到 Peek
• 浅色和深色主题
• 简体中文、英语、德语、法语、意大利语、西班牙语、葡萄牙语、巴西葡萄牙语、波兰语和俄语

私密且开源
Peek 不展示广告，也不出售数据。它自己绘制地图，所以没有任何地图服务能看到你的包裹去了哪里。不登录跟踪的包裹会在送达 30 天后被清除。你随时可以在 App 中下载你的数据或删除账号。所有代码都在 GitHub 上：github.com/plhery/peek-delivery-tracker

Peek 独立于它所查询的快递公司。这些公司的名称归各自的所有者所有。
```

## What's new

```text
• 在“添加包裹”中，每家快递公司现在都有各自的邮编和收件国家/地区：切换快递公司时，上一家的邮编不会再带过去，切换回来时会重新显示。
• “更换快递公司”现在会用你上次填写且格式相符的邮编填入必填的邮编栏，并在可选的邮编栏中推荐它，和“添加包裹”一样。
• 已保存邮编的包裹（例如还没有扫描记录的 PostNL 包裹）不会再第二次要求填写收件邮编。
• Peek 现在新增支持 83 家快递公司，每家都有自己品牌色的货车，其中包括 GLS US、BH Pošta、Pošte Srpske，以及希腊、罗马尼亚、匈牙利、波兰和保加利亚的快递公司。
• 如果一个单号没有任何快递公司查到，开头却像某家快递公司的单号，只是少了或多了一个字符（例如以 1Z 开头的 UPS 单号），包裹页面现在会提示可能输错了，并写出是哪家快递公司。
• 物流记录下方现在有一行说明时间按你所在的时区显示，并写出时区名称，例如“中欧时间”。
• 通知和实时活动里的派送时段现在按快递公司给出的时间显示，英国 07:00–09:00 的时段不会再显示成 08:00–10:00。
• 在负责派送的快递公司扫描包裹之前（例如 JRT 交给 DHL 的包裹），Peek 现在会在最多 14 天内继续查询第一家快递公司，让它之后的扫描记录仍能显示出来。
• 包裹退回寄件人途中，通知现在显示“正在退回”而不是“在路上了”；Peek 也会继续查询，以防它最后还是安排派送。
• 对于会提前写好物流节点（甚至包括签收）的快递公司，例如 GZYL 和 Xinghe Freight，包裹页面现在会说明 Peek 不显示这些节点，并建议你到其网站上查找在你所在国家派送的快递公司。
• AliExpress 包裹的物流记录中，菜鸟的“Last-mile delivery forecast”现在显示为“已通知当地快递公司”。
• 使用最大字号时，在 iPhone SE 等小屏 iPhone 上，欢迎页面上的“登录”和示例包裹名称不会再互相重叠或压到路线上：图片会随之变大，页面可以滚动。
```
